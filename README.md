# 🌌 About The Project

**NIRVAN '26** is a modern technical fest website designed for
**Graphic Era Hill University, Haldwani Campus**.

The platform provides a complete digital experience for students,
developers, gamers, innovators and technology enthusiasts.

Instead of being just a static event website, NIRVAN is designed as an
**interactive event ecosystem** where users can:

- 🔎 Discover events
- 🏆 Explore competitions
- 📅 View schedules
- 🎤 Discover speakers
- 🤝 Explore sponsors and communities
- 📸 View event highlights
- 🚀 Join the Campus Ambassador program
- 📍 Find venue and contact information
- 📝 Register for events

> **Where Ideas Become Innovation.**
